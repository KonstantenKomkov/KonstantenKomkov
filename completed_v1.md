Критерий готовности: пустой сценарий выполняется локально, зависимости направлены от внешних адаптеров к внутренним слоям через интерфейсы.

Результат:

- CLI запускается командой `make run`, а `validate-config` безопасно проверяет конфигурацию из переменных окружения;
- архитектурный тест контролирует допустимые зависимости между слоями;
- команды `make format`, `make lint`, `make typecheck`, `make test` и `make check` используют закреплённые версии инструментов.

Принятые ограничения:

- Python 3.9 или новее;
- runtime-зависимости отсутствуют;
- конфигурация читается только из окружения, приватные значения не выводятся.

Артефакты: `src/it_activity/`, `tests/`, `pyproject.toml`, `requirements-dev.lock`, `Makefile`, `docs/configuration.md`.
