# Правила сбора активности

Команда `it-activity collect` выполняет следующие действия:

1. Проверяет, что read-only токен принадлежит настроенному GitHub login.
2. Получает с пагинацией все репозитории, на которые у токена есть явное право
   чтения, включая приватные.
3. Получает с пагинацией все текущие ветки каждого репозитория и коммиты между
   началом первого из последних 365 календарных дней и текущим моментом.
4. Дедуплицирует коммиты по SHA глобально, до загрузки файлового diff.
5. Оставляет только коммиты с явно настроенным авторским email и группирует их по
   календарным дням настроенного часового пояса.
6. Загружает все страницы файлов учтённого коммита и сверяет суммы с общей
   статистикой GitHub. Потенциально усечённый ответ не публикуется.

Для строк кода используется детерминированный allowlist расширений и имён
исходных файлов. Бинарные файлы, каталоги generated/build/dist, vendored-каталоги,
lock-файлы, документация и неизвестные типы файлов исключаются. Классификация не
читает и не выводит содержимое, путь или имя приватного файла.

Публичный JSON команды содержит только дату, количество коммитов, добавленных и
удалённых строк и название настроенного часового пояса. Названия репозиториев,
веток, файлов, сообщения коммитов и авторские email в результат не попадают.
